# GCUF Career Counselor AI

An AI-powered career counseling platform designed for GCUF students. The system helps students explore career paths, degree programs, job opportunities, and future career trends through an interactive AI assistant.

## Features

- AI-powered career counseling
- Career exploration guidance
- Academic program information
- Personalized recommendations
- Job market insights
- English and Urdu support
- Responsive modern interface

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Google Gemini AI

## Installation

```bash
npm install
npm run dev
